# Stage013 external validity and public-data follow-up

Checked2026-11-28 after protocol freeze; these findings do not change the running matrix.

The [source paper v2](https://arxiv.org/html/2508.17086v2) uses three NASDAQ stocks on2015-01-02, a cascaded pretrained LOB representation and supervised contrastive fusion, then an anomaly detector. Its proposed training set contains388manipulated orders among1,239,632orders (about0.03%); its test ratio is5.04%. It reports0.675AUC-PR for proposed JFDS plusOC-SVM. Stage013 instead uses WSE windows, about5%training positives, a6000window cap, compactTransformer and a price-aligned fusion input. Thus same-cohort stage013 contrasts are defensible external adaptations, not exact original-paper reproduction or a comparable0.675threshold. Generic representation code does not establish access to the original injected labels.

[LOBench's author repository](https://github.com/Financial-Simulation-Lab/LOBench) contains a representation model zoo and cites the manipulation paper as a downstream application. The inspected tree c8fe9e701405d553b278cba063012107bd8ec718 and README blob d783f25feddb6cfa0e39cb323d1459984cac42fa do not establish that it releases the exact target detector and original labels. The README links an expanded author release onHuggingFace.

The [public dataset card](https://huggingface.co/datasets/mythezone/LOBench-A-share-processed/raw/main/README.md) declares MIT licensing and279,815processed windows across50aliased A-share assets. The [panel documentation](https://huggingface.co/datasets/mythezone/LOBench-A-share-processed/raw/main/deidentified_50stock_panel/README.md) describes ten relative trading days perasset, chronological7/1/2splits,100states perwindow,8state stride,3second sampling,40ten-level price/volume features, training-only invertible affine normalization, and trend labels. Absolute dates/tickers and the raw message feed are withheld. The [code guide](https://huggingface.co/datasets/mythezone/LOBench-A-share-processed/raw/main/code/README.md) gives full benchmark commands. Documentation was retrieved via bounded public HTTP requests after the web tool failed; SHA256 receipts are in results/engineering/components-013/lobench-metadata-discovery.json. No market tensors were downloaded, no new dataset is counted as acquired, and no third-party models were run.

Our inference: this is a concrete second-market follow-up candidate, not a substitute for complete event-day WSE archives or verified spoofing labels. Overlapping windows must stay within source-day groups. Three-second sampling cannot preserve event-level cancellation timing; seconds_since_midnight and relative_day_id cannot recover absolute dates. A separate protocol must audit price/volume recovery, duplicated windows, sampling resolution, permissible derivatives and the synthetic label policy before any detector fit. Provider release tags and per-file hashes should be pinned. The card's reported journal acceptance is an author statement; no DOI or venue ranking is inferred.

[Fabre and Challet](https://arxiv.org/abs/2504.15908) model expected spoofing profitability from distance-sensitive event flow and conditional price distributions using Level3crypto observations. Their suspicious-order criterion is not our policy-label AP target. SUNZU-supplied source data are described, but an open redistribution license for their exact feed was not established. ArXiv history dates the paper2025-04-22; a date printed in HTML is not evidence of a new2026method.

[Chen and Glasserman](https://arxiv.org/abs/2608.23706), submitted2026-08-24, test simulated LOB state consistency and spurious predictability despite apparently valid generated sequences. It is not a spoofing-detector baseline. Our inference: structural validity and high synthetic scores are insufficient evidence of mechanism fidelity. [Kularatnam and Stathaki](https://arxiv.org/abs/2403.13429) use weak labeling, TCN representations and expert/complex-algorithm triage; it is older workshop work, not a newly reproduced2026baseline. These works clarify gaps without inflating our executed method count.

中文结论：已核实一个有明确公开文档和许可声明的50资产第二市场线索，但它是重叠、三秒采样、相对日期的趋势预测窗口，不能直接计入完整交易日操纵实验。原论文标签预算与本轮差异显著；当前结论必须限定为同协议外部评测。
