# Direct supervision and hard-negative evaluation / 阶段012

Stage011 showed price-aligned depth features helped, but its contrastive cascade lost to strong supervised controls. Stage012 therefore uses direct prediction of the binary generated policy label and removes the unsupervised raw-book reconstruction stage. The previous test results are development evidence only. New dates are frozen before inspecting any new detector performance: Jan19/20/23 train, Jan24/25/26 validation, Jan27/30/31 test, 2017, five WSE stocks. The same passive lifecycle/censoring mechanism uses generator seed17088. This adds45 complete stock-days and leaves3 independent test dates, not30 independent markets.

Ten methods compare full-input logistic/HGB/MLP with and without hard-negative weights, and full-input-plus-interaction HGB/MLP with and without those same weights. Full inputs are exactly500 raw,125 available manual and1000 aligned-flow coordinates. The488 new coordinates describe addition/removal co-occurrence, lags0/1/2/4/8/12, time centers/dispersion and synchronized breadth. They use no labels, stock/date IDs, injection metadata or post-window data. Price alignment occurs in the input flow calculation; interaction features do not infer missing order identities. They describe the completed25-event window, not causal alerts before its endpoint.

Mining uses a fixed60-iteration15-leaf HGB on interaction features, with three training-stock-day GroupKFold partitions. A sample's mining score is produced without fitting its group. The highest-scoring10% of training negatives receive5x relative weight; each class is then renormalized to half the total weight. All classifier families share identical saved weights and training IDs. The miner has access only to training binary labels. It never receives validation/test or the synthetic benign-kind label. This does not create extra real supervision. A shared training cap of12000 random, seed-fixed windows bounds resource use; all methods use the same subset.

Implementation clarification added after the pilot on2026-11-27; no code/config change: all hard-weighted variants use the same interaction-feature miner, including scorers whose own predictors are base-only. Thus interaction_mlp_hard versus mlp_hard isolates scorer features conditional on that shared miner; it is not an ablation that removes interaction features from every pipeline stage. The interactions are deterministic transforms of shared observed inputs, not additional market observations. Mining time is shared run overhead; per-method fit time excludes it.

Every model has six validation-only hyperparameter trials. MLP uses a roughly200k-parameter two-hidden-layer ReLU head, weighted BCE, AdamW and20 epochs with batch256, no early stopping. HGB retains the previous7/15/31-leaf by.03/.1 learning-rate grid and100 iterations; logistic uses six predeclared C values. Learning grids and constants are in configs/012-preregistered.json. Features are standardized and constant columns removed using the selected training subset only. Model weights, scaler masks, mining scores/folds, all trial metrics/warnings, selected estimators and predictions are retained.

Primary matrix: five training seeds for pooled chronological date split plus five date-and-stock holdouts:30 fold-seeds and300 selected evaluations. The validation stock is the next stock in the fixed alphabetical list. Each date block contains3days. Report pooled AP and paired macro stock-day AP, benign/background FPR and recall at a validation-calibrated1% overall-negative FPR threshold. A nominal overall threshold is not a1% guarantee for benign bursts. Seeds are averaged before exploratory date/stock cluster resampling; only3test dates remain a serious limitation. No algorithm or hyperparameter revision after viewing this cohort's test outcomes.

Runtime qualification precedes a scientific date/seed0 pilot, then remaining fixed runs. GPU/CPU budgets use measured memory plus headroom; all scientific fitting is CQ-only on the official free backend. No paid rental. Canonical main preserves inputs/results; execution-only Git trees carry unchanged code plus needed inputs to avoid repeated historical uploads. All jobs are queried before submission and unrelated workloads remain untouched.

This tests a supervised risk-pattern detector on a semi-synthetic public benchmark. It does not establish real manipulation intent, endogenous market reaction, exact original LOBSTER reproduction, superiority to the paper's0.675, or CCF A readiness. A stronger feature-engineered HGB result is a pipeline improvement, not evidence that neural scoring is necessary.
